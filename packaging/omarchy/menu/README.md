# Omarchy menu provider

`SynchroSearch.qml` is the asynchronous search adapter used by a user-owned
clone of Omarchy's first-party `omarchy.menu` plugin. It deliberately does not
replace the menu's normal application and command ranking:

- ordinary searches query Synchro after three characters and place three hits
  after the five strongest Omarchy results;
- `/query` explicitly searches only the indexed file catalog and returns eight;
- whitespace-separated filename terms use AND semantics, so `test pdf` must
  contain both terms in the basename;
- `// text` runs the app's bounded literal in-file search and labels those
  results as content matches;
- warm Synchro thumbnails are exported to the per-session runtime directory
  and used as dynamic QML icons; cold previews are never generated by search;
- Enter locates a result in Synchro (`--select` for files), while Ctrl+Enter
  performs the ordinary system open/execute action;
- each request is debounced, stale processes are stopped, and stale responses
  are discarded;
- activation uses argument arrays rather than interpolated shell commands.

Omarchy currently has no cross-plugin search-provider registry, so the small
host patch lives in `omarchy-menu.patch`. Dogfood it with a supported local
clone (`omarchy plugin clone omarchy.menu`) and apply the patch to that clone.
The package may install these assets under `/usr/share/synchro`, but must not
write into `~/.config/omarchy` without an explicit user command.

`synchro-omarchy-menu-install` is that explicit command. It validates the
clone and patch before changing anything, then uses Omarchy's supported
shell-only restart so the keep-loaded menu cannot retain stale QML.
